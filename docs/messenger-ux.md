# Сообщения: устройство экрана (общее для сайта и приложения)

Образец — переписка Worldpackers и привычные мессенджеры. Сайт (`apps/web/src/components/messenger`) и мобильное приложение (gs-mobile, `src/screens/chats`) повторяют одно и то же поведение; меняя одно, меняйте и другое.

## Список переписок

- Сверху поиск по имени (на сервере, после паузы в наборе) и вкладки: **Все · Непрочитанные · Ждут ответа · Принятые**. У «Непрочитанных» и «Ждут ответа» — счётчик.
  - «Ждут ответа» — последнее сообщение от собеседника.
  - «Принятые» — заявка в переписке принята.
- Загружается весь список (API отдаёт страницами, берём все), вкладки фильтруют в клиенте.
- Строка:
  1. аватар собеседника; имя (жирное, если есть непрочитанные); время последнего сообщения: сегодня — «14:05», вчера — «Вчера», на неделе — день недели, в этом году — «5 нояб.», раньше — дата;
  2. плашка статуса заявки и «вакансия · даты» (из `chat.application`);
  3. последнее сообщение: своё — с галочкой (одна — отправлено, две — прочитано собеседником) и «Вы:»; справа — число непрочитанных.
- Плашки статуса: у новой заявки организатор видит «Новая заявка», волонтёр — «Заявка отправлена»; дальше «Принята» / «Отклонена».
- Состояния: загрузка (заглушки строк), ошибка с «Повторить», пусто («Переписок пока нет» / «Здесь пока пусто» во вкладке).

## Переписка

- Шапка: назад (телефон), аватар и имя (ссылка на профиль), под именем — плашка статуса, вакансия (ссылка) и даты; справа — «Информация» о собеседнике.
- Организатору у новой заявки — полоса под шапкой «Новая заявка — примите или отклоните её…» с кнопками **Отклонить** и **Принять** (зелёная). После решения плашка меняется сразу, полоса пропадает.
- Сообщения: свои — синие справа, собеседника — белые слева. Подряд идущие сообщения одного автора в пределах 5 минут — группа: аватар собеседника только у последнего, отступы внутри группы меньше. Время — внутри пузыря, у своих — галочки прочтения.
- Разделители дней: «Сегодня», «Вчера», «5 ноября» (в прошлые годы — с годом).
- Заявка в ленте — карточка посередине: «Имя подал заявку на вакансию», название вакансии (ссылка), даты.
- На телефоне открытая переписка — на весь экран.
- Картинки во вложениях — с зарезервированным местом и заглушкой, пока грузятся.

## Данные API

- `GET /api/v1/personal/chats?page=N&itemsPerPage=100[&search=]` — у чата `application`: `id`, `status`, `startDate`/`endDate` (ГГГГ-ММ-ДД), `vacancyId`, `vacancyTitle`, `vacancyImage`, `organizationId`, `organizationName`; `lastMessage.readByUserIds` — для галочек.
- Кто вошёл в этой переписке: организатор, если `application.organizationId` — его организация.
- Решение по заявке — `PATCH /api/v1/application_forms/{id}/status`.
